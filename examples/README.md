# 示例文件说明

这个目录包含了 DOMjudge 账号生成器的示例文件，帮助您理解输入输出格式。

## 📂 文件说明

### 输入文件
- **`example_input.txt`** - 示例输入文件
  - 格式：每行包含一个学生的信息
  - 分隔符：Tab（制表符）
  - 结构：学号[Tab]姓名

### 输出文件（自动生成）
- **`teams.tsv`** - 队伍信息文件，用于 DOMjudge 导入
- **`accounts.tsv`** - 账号信息文件，包含登录凭据

## 🚀 快速开始

### 1. 使用示例文件
```bash
# 进入项目目录
cd DomjudgeTools

# 使用示例文件生成
python generator.py examples/example_input.txt
```

### 2. 输入格式要求
```
学号         姓名
2307110101  黄宇
2307110103  向燕萍
2307110104  邓诗榕
```

### 3. 输出格式说明

#### teams.tsv
```
teams	1
2307110101	GXU2307110101	3	黄宇				
2307110103	GXU2307110103	3	向燕萍				
```

#### accounts.tsv  
```
accounts	1		
team	黄宇	2307110101	12345678
team	向燕萍	2307110103	87654321
```

## 📋 字段说明

### teams.tsv 字段
1. **学号** - 学生学号
2. **队伍ID** - 自动生成，格式为 GXU + 学号
3. **类别** - 默认为 3
4. **姓名** - 学生姓名
5. **后续字段** - 保留空白，用于其他信息

### accounts.tsv 字段
1. **类型** - 固定为 "team"
2. **姓名** - 学生姓名
3. **学号** - 学生学号（用作用户名）
4. **密码** - 自动生成的8位数字密码

## 💡 使用提示

1. **文件编码**：确保输入文件使用 UTF-8 编码
2. **分隔符**：必须使用 Tab 字符分隔，不是空格
3. **空行**：程序会自动忽略空行
4. **密码**：每次运行生成不同的随机密码
5. **Excel支持**：也可以使用 .xlsx 或 .xls 文件，前两列分别为学号和姓名
